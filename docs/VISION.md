# BossJobs · 产品总目标

> **本文只写「最终要达成什么」，不写怎么做。**  
> 实现方式、技术选型、接口路径、包结构等见其他专项文档。

---

## 一句话

做成个人向的**多平台求职情报台**：按「城市 + 关键词」批量拿到岗位与公司信息，本地留存、可去重、可分析、可导出，人与 AI 都能用，Web 能点一下就跑采集。

---

## 为何存在（相对现有开源）

市面上多为单平台脚本、油猴助手、自动打招呼/投递，或「采集后即丢」的临时工具。  
BossJobs 要对齐的是完整闭环：

**搜得到 → 存得住 → 不重复 → 看得清 → 背得了公司 → AI 调得动 → Web 用得顺。**

参考方向（定位对照，非照搬）：

| 类型 | 代表 | 我们相对补齐的 |
|------|------|----------------|
| Boss 采集 / Agent | BossHunter、boss-zhipin-scraper、Boss_direct_hire | 多平台统一字段 + 本地情报库 |
| Boss 浏览器助手 | boss-helper | 不依赖页面油猴；以情报与分析为主，不做一期自动投递 |
| 多平台投递自动化 | job-hunter（Boss/鱼泡/51）、Auto-JobHunter | 一期不投递；先把「采全 + 分析 + 背调」做实 |
| 智联 / 鱼泡 | 公开仓库少、多为零散脚本或投递 skill | 智联纳入核心平台；鱼泡作为后续平台目标 |

## 最终功能目标

### 1. 多平台岗位情报

- 能从主流招聘站拿到可比的结构化岗位数据。
- **当前目标平台：** Boss 直聘、智联招聘。
- **后续目标平台：** 鱼泡直聘等（同一套产品能力扩展，而不是另起一套工具）。

### 2. 按「关键词 × 城市」批量搜索

- 用户可指定一个或多个求职关键词（如「AI 开发」「Agent 开发」）。
- 用户可指定目标城市（如「重庆」）。
- 一次任务可覆盖多关键词、可翻页拿全列表范围内的岗位。

### 3. 岗位信息采全

对每条岗位，最终应能沉淀：

- 岗位名称  
- 工作地点 / 位置  
- 薪资区间  
- 福利待遇  
- 是否双休 / 休息制度（有则明确，无则允许为空）  
- 岗位 JD 全文  
- 公司名称  
- 来源平台与抓取时间（便于追溯）

### 4. 采集驱动方式

- **CLI：** 人可命令行跑采集；AI 也可直接调用同一套命令拿到结构化结果。  
- **Web：** 在前端一点即可发起采集任务，并看到任务状态与结果。  
- 产品形态是「采集能力 + CLI + Web」一体，而不是二选一。

### 5. 本地沉淀与去重

- 所有岗位进入个人本地情报库。  
- 同一平台同一岗位重复采集时不堆垃圾数据，以更新为准。  
- 历史数据可反复查询、筛选、分析，不必每次重爬。

### 6. 导出

- 支持将岗位及相关信息导出为 **Excel**，便于线下筛选与分享。

### 7. Web 情报台

- 岗位列表：强筛选（城市、平台、关键词、薪资等）。  
- 岗位详情：JD、福利、休息、公司等一眼看清。  
- 采集任务页：创建、启动、查看进度。  
- 分析看板：图表清晰，交互顺畅，有必要的动效（服务理解，不堆装饰）。  
- 设置：登录态 / 凭证配置、背调相关配置等。

### 8. 数据分析

最终要能直接回答求职决策问题，例如：

- 某个关键词下，**各城市岗位数量**如何分布？  
- 某个关键词下，**各城市薪资水平**如何（区间、中位/均值、样本量）？  
- 后续可扩展：福利词频、双休占比、高频公司等（不阻塞主目标）。

图表能力目标：支持专业、可读的可视化看板（柱状、分布等），筛选与图表联动。

### 9. 公司背调

输入公司名称后，尽量看到：

- 经营状况  
- 注册时间  
- 注册资金  
- 社保缴纳人数  
- 在职 / 规模相关人数  
- 相关案件 / 风险摘要  

原则：**有则展示，无则标明暂无**；背调失败不得拖垮岗位采集主流程。

### 10. 给人与 AI 的统一入口

- 提供可安装的 CLI，作为人与 AI 的主调用面。  
- 输出可被程序/模型稳定解析（结构化结果）。  
- 后续可再包一层 AI 协议入口（如 MCP），不改变上述能力目标。

### 11. 认证与可用性目标

- 用户使用自己的招聘站登录态完成采集。  
- 支持预先登录或导入会话，之后 CLI / AI / Web 采集无需每次手工登录。  
- 凭证与数据默认留在本机，不做默认多用户云端 SaaS。

### 12. 明确不做（当前产品边界）

- **一期不做**自动打招呼 / 批量投递（可预留扩展口）。  
- **不做**默认上云的多租户求职 SaaS。  
- **不承诺**公司背调字段 100% 齐全。  
- **不承诺**休息制度在所有岗位上都有明确值（依赖平台信息与 JD 可解析程度）。

---

## 成功标准（用户可感知）

1. 指定「重庆 + AI/Agent 类关键词」，能从 Boss、智联把目标字段岗位采全并入库。  
2. 重复跑同一搜索，库内不出现大量重复岗位。  
3. Web 可筛选浏览、可点采集、可看城市数量与薪资分析图。  
4. 可按公司名查看背调（有数据则展示）。  
5. 可导出 Excel。  
6. AI 通过 CLI 能完成：采集、查岗、分析、查公司，并得到结构化结果。
